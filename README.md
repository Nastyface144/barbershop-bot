# 💈 Barbershop Bot

Демо Telegram-бота для онлайн-записи в барбершоп. Клиент выбирает услугу, мастера, дату и время прямо в чате, без звонков. Администратор получает уведомления и управляет расписанием.

**Стек:** Python 3.11+, aiogram 3, SQLite (aiosqlite), APScheduler.

## Возможности

### Для клиента
- **Главное меню** на инлайн-кнопках: «Записаться», «Мои записи», «Услуги и цены», «Контакты».
- **Запись в 4 шага:** услуга → мастер → дата → время, затем подтверждение с итогом.
- **Календарь на 14 дней вперёд.** Прошедшие и полностью занятые дни недоступны.
- **Только свободное время.** Бот учитывает длительность услуги, занятость мастера и закрытые администратором часы.
- **Кнопка «Назад»** на каждом шаге.
- **«Мои записи»:** список предстоящих визитов с отменой в два нажатия.
- **Напоминания** за 24 и за 2 часа до визита.

### Для администратора
- **Уведомления** о каждой новой записи и отмене.
- **`/admin`:** записи на сегодня и завтра.
- **Закрытие дня или отдельного времени** через календарь. Уже созданные записи при этом сохраняются.

### Интерфейс и надёжность
- **Одно сообщение.** Бот редактирует его, а не присылает новое на каждое нажатие.
- **Без двойных записей.** Если два клиента одновременно нажмут на одно время, запишется только один.
- **Переживает перезапуск.** Выбор клиента хранится в кнопках, а отметки о напоминаниях в базе.
- **Ошибки не роняют бота.** Они логируются, а пользователь видит понятное сообщение.

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:

```bash
git clone https://github.com/Nastyface144/barbershop-bot.git
cd barbershop-bot
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

4. Создайте файл `.env` по образцу:

```bash
cp .env.example .env           # Windows: copy .env.example .env
```

```env
BOT_TOKEN=123456789:AAAA-your-token-here
ADMIN_ID=123456789             # можно несколько через запятую
TIMEZONE=Europe/Moscow
DB_PATH=barbershop.db
```

5. Запустите бота:

```bash
python -m bot
```

6. Напишите боту `/start`. Под аккаунтом из `ADMIN_ID` также доступна команда `/admin`.

> Администратор должен хотя бы раз написать боту `/start`, иначе Telegram не даст боту отправлять ему уведомления.

## Запуск на VPS (24/7)

На сервере с Ubuntu или Debian подключитесь по SSH под `root` и выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/Nastyface144/barbershop-bot/main/deploy/install.sh | bash
```

Скрипт поставит Python и зависимости, спросит токен бота и ваш Telegram ID и настроит автозапуск. Бот будет работать круглосуточно и сам перезапустится после сбоя или перезагрузки сервера. Повторный запуск той же команды обновляет бота до последней версии.

Полезные команды:

```bash
journalctl -u barbershop-bot -f       # лог бота (выход: Ctrl+C)
systemctl restart barbershop-bot      # перезапуск
nano /opt/barbershop-bot/.env         # изменить токен или ID, затем перезапуск
```

## Структура проекта

```
bot/
├── __main__.py          # точка входа: запуск бота и планировщика
├── config.py            # настройки из .env и рабочий график
├── demo_data.py         # название, контакты, мастера, услуги
├── texts.py             # тексты всех экранов
├── middlewares.py       # автоответ на нажатия кнопок
├── database/
│   ├── db.py            # работа с SQLite
│   └── models.py        # модели данных
├── handlers/
│   ├── common.py        # /start, меню, услуги, контакты
│   ├── booking.py       # пошаговая запись
│   ├── appointments.py  # «Мои записи» и отмена
│   ├── admin.py         # панель администратора
│   ├── fallback.py      # ответы на неизвестные сообщения
│   └── errors.py        # глобальный обработчик ошибок
├── keyboards/
│   ├── callbacks.py     # callback-данные кнопок
│   ├── calendar.py      # инлайн-календарь
│   ├── client.py        # клавиатуры клиента
│   └── admin.py         # клавиатуры администратора
├── scheduler/
│   └── reminders.py     # напоминания через APScheduler
├── services/
│   ├── slots.py         # расчёт свободного времени и создание записи
│   └── notify.py        # уведомления администраторам
└── utils/
    ├── formatting.py    # даты, цены, время на русском
    └── render.py        # редактирование одного сообщения
```

## Настройка под клиента

- **Название, адрес, телефон, мастера и услуги:** `bot/demo_data.py`. Мастера и услуги записываются в базу при первом запуске, поэтому после их изменения удалите `barbershop.db`.
- **График работы, шаг сетки, глубина записи:** константы в `bot/config.py` (`WORK_START_MIN`, `WORK_END_MIN`, `SLOT_STEP_MIN`, `BOOKING_DAYS`, `MIN_LEAD_MIN`).
- **Тексты сообщений:** `bot/texts.py`.
